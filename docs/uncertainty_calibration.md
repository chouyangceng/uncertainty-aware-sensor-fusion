# 位置协方差校准与 NEES 实验

融合系统输出一个位置和一个协方差矩阵。位置 RMSE 只回答“平均错多远”，协方差校准还要回答“系统声称的置信范围是否可信”。如果名义 95% 置信椭圆只覆盖 70% 的真实目标，系统即使 RMSE 看起来不错，也在危险地低估不确定性。

## 运行

```bash
python experiments/uncertainty_calibration.py --fast --seed 7
```

去掉 `--fast` 使用 20000 个异方差样本。输出目录非空时默认拒绝覆盖，可用 `--overwrite` 明确更新。实验生成：

- `calibration.json`：严格 JSON 指标与元数据；
- `coverage.csv`：每个名义置信度的经验覆盖率和偏差；
- `calibration_curve.png`：名义置信度—真实覆盖率曲线；
- `nees_distribution.png`：经验 NEES 分布与理论二维卡方目标；
- `whitened_residuals.png`：白化残差和报告的 95% 椭圆；
- `summary.md`：中文结论和适用边界。

## 指标

对二维位置误差 \(e_i\) 和报告协方差 \(P_i\)，归一化估计误差平方为：

\[
\operatorname{NEES}_i=e_i^\mathsf{T}P_i^{-1}e_i.
\]

当零均值高斯假设成立且协方差校准正确时，NEES 服从自由度为 2 的卡方分布，均值应接近 2。二维卡方分位数有闭式解 \(q(p)=-2\log(1-p)\)，因此核心指标只依赖 NumPy，无需 SciPy。

对每个名义置信度 \(p\)，实验统计 `NEES <= q(p)` 的样本比例作为经验覆盖率。平均绝对覆盖偏差是校准误差。`overconfident` 和 `underconfident` 标签使用平均 NEES 相对 2 的透明容差阈值作教学提示，正式研究应结合有限样本置信区间和应用风险设定阈值。

## 受控场景

四个场景复用完全相同的误差，只改变系统报告的协方差：

1. `calibrated`：报告真实异方差协方差；
2. `underreported_40pct`：只报告真实协方差的 40%，模拟危险过度自信；
3. `conservative_200pct`：报告两倍协方差，模拟过度保守；
4. `correlation_ignored`：保留边缘方差但删除相关项。

真实协方差随目标距离和朝向变化，因此实验同时覆盖不同尺度和旋转的置信椭圆，而不是只验证一个固定圆形噪声模型。

## 边界与后续

实验假设已正确关联目标且误差近似零均值高斯，不覆盖漏检、错误关联、遮挡导致的多峰误差或长尾分布。真实验证应按距离、天气、目标类别、遮挡程度和传感器健康状态分层，并用 bootstrap 或二项区间报告覆盖率的不确定性。
