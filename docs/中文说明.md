# 中文说明

## 高级代码模块

- `calibration/online.py`：用对应点递推估计小范围外参平移误差；
- `synchronization/latency.py`：用有限滞后扫描估计两路信号延迟；
- `fusion/occupancy.py`：将目标点更新到带 log-odds 的 BEV 占据栅格；
- `tracking/manager.py`：维护多目标轨迹生命周期和丢失计数；
- `reliability/manager.py`：根据滑动窗口有效率计算传感器健康度。

高级 benchmark 运行后应同时记录标定残差、延迟、占据概率、轨迹 ID 保持情况和健康度分数，不能只报告融合位置误差。

## 项目用途

相机擅长语义，LiDAR 擅长几何，Radar 擅长速度，但三个传感器的坐标系、频率、延迟和噪声都不同。本项目先解决这些工程问题，再做带置信度的目标融合和跟踪。

## 代码对应关系

- `geometry/transforms.py`：点云坐标变换与相机投影；
- `synchronization/buffer.py`：单调时间戳和最近邻缓存；
- `calibration/camera_lidar.py`：LiDAR 点投影到图像；
- `fusion/geometry_fusion.py`：按对象 ID 做目标级融合；
- `tracking/kalman.py`：四维位置/速度 Kalman 跟踪和离群门控；
- `reliability/gating.py`：协方差权重和传感器健康度；
- `experiments/runner.py`：相机噪声、LiDAR 缺失和 Radar 噪声实验。

## 坐标和单位

点云使用米，齐次变换使用 4×4 矩阵，图像投影使用像素坐标。代码会拒绝非有限点、错误矩阵形状和相机后方点。

## 结果解释

`camera_only_position_rmse` 是单相机基线，`fused_position_rmse` 是完整融合，`missing_lidar_position_rmse` 是 LiDAR 失效后的降级结果。数字只用于当前仿真协议的比较。
